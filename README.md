# CC3067 - Laboratorio 3: Protocolos de Enrutamiento

Simulador de una red de routers Link State (HELLO, LSA, flooding, Dijkstra)
que enruta mensajes de datos entre un cliente y un servidor, aplicando
Hamming(7,4) en el plano de datos.

Este repositorio tiene dos carpetas principales:

- [`informe/`](informe/) - el reporte final en PDF con resultados y discusion.
- [`proyecto/`](proyecto/) - todo el codigo (routers en Python y Go, pruebas,
  documentacion del protocolo y los scripts que reproducen los experimentos). Ver
  [`proyecto/README.md`](proyecto/README.md) para instrucciones de ejecucion y
  [`proyecto/docs/protocol.md`](proyecto/docs/protocol.md) para la especificacion
  completa del protocolo (acordada con las demas parejas de la topologia).
